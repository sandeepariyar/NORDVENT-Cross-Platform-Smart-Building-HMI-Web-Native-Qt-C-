04 / CASE STUDY
Design to embedded engineering.
A visual system rebuilt across implementations while retaining room-level behavior and meaningful interactions.
THE CHALLENGE
Make a complex building intelligible in 800 × 480.
NORDVENT explores how an architectural overview can carry real control meaning without becoming a grid of conventional admin panels. The primary challenge was preserving visual hierarchy, readable status and direct room interactions under fixed embedded display constraints.
THE APPROACH
Retain the scene. Change the renderer.
The HTML implementation established the original v17 visual behavior: room camera presets, 15-frame architectural media, lighting overlays, ventilation circuits, blinds and multiple subsystems. The native Qt implementation reconstructs those interactions in QML and separates control state into C++.
THE HARD PROBLEMS
Animation alignment, motion and event truth.
Subtle faults become obvious at embedded resolution: flow markers departing the duct lines, a fan baked into a static image, or blinds that do not physically fold. The native v17.1 iteration corrects these using predefined coordinates, a separate rotating rotor and repeatable raster slats.
WHAT COMES NEXT
From simulation to trustworthy device control.
A real installation requires telemetry quality, command acknowledgments, independent protection logic, device gateways, persistent settings and hardware testing. Those are specifically documented as future work rather than portrayed as complete.
Room focus — original v17 design reference
“The same interface idea should remain legible across browser, native desktop, and ultimately constrained hardware.”
