05 / ENGINEERING CASE STUDY
When visual fidelity meets system constraints.
This project investigates the same interface concept across independent renderers. Each port tests what can be preserved, what must change, and what needs real hardware evidence.
01 / PROBLEM
Complex information.
A constrained screen.
Present ventilation, lighting, heating, blinds, room context and safety status inside an 800 × 480 touchscreen, without losing architectural clarity.
02 / DECISIONS
One visual contract.
Separate implementations.
Keep system state in native C++, compose image-backed architecture in QML, preserve original CSS/SVG as the browser reference, and document each tradeoff.
03 / HARD PROBLEMS
Animation must follow
the actual geometry.
Fan blades must rotate, blinds must move like slats, and flowing dots must stay on the designed ducts—without misalignment between camera views.
04 / EVIDENCE
Show the implementation.
Label the unknowns.
Browser behavior is inspectable; source metrics are reproducible. Physical MCU deployment, telemetry acknowledgments and timing budgets remain separate verification steps.
