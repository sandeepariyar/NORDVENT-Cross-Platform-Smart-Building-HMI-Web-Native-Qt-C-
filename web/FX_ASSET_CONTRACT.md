`assets/rooms/*.webp` are matched crops derived from the same master image, darkened by UI scrims so text stays legible. They are **visual identifiers only**, not sensor images or live cameras.

## Rendering order

1. Photographic unlit house base.
2. Independent cropped illumination PNG passes, one for each fixture.
3. Target-temperature SVG tint polygons (low-opacity, independent per room).
4. Rooftop fan, cyan airflow, heat recovery, and amber heating paths.
5. Violet motorized-blind slats, masked by each room's state (0% open; 50% partly closed; 100% closed).
6. Room outlines/hotspots and application UI.

The temperature tint visualizes **requested room target setpoints**, not measured ambient values. Other system indicators remain simulated. SVG opacity/color/geometry are generated by `updateEffects()` in `app.js`. Each layer can later be represented as an independently controlled image or cropped sequence in an embedded implementation.

When the underlying building image changes, recalculate these alignments; they are not universally reusable. This is illustrative architectural overlay art, not a certified mechanical/airflow plan.
